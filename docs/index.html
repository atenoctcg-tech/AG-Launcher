Help

Frequently asked.

What is AG Launcher?+

AG Launcher is the Windows desktop launcher for Atenoct Games. It installs, updates and launches Atenoct titles from one app.

Where does the download come from?+

The site queries the official AG-Launcher repository and links directly to the newest public GitHub Release asset.

Is the website hosting free?+

Yes. This site is designed for GitHub Pages and does not require a paid server.

Can paid games be supported later?+

Yes, but real ownership must be verified by a secure backend rather than a public manifest.
