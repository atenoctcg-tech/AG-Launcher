# Atenoct Games GitHub Pages website

The website is published from the `/docs` folder and connects to:
- GitHub Releases for AG Launcher downloads, version and release notes
- `launcher-manifest.json` for games, news and social links

Enable it once in **Settings → Pages → Deploy from a branch → main → /docs**.

Expected free URL:
https://atenoctcg-tech.github.io/AG-Launcher/

To activate direct launcher download, create a public GitHub Release and attach the Windows x64 ZIP.
